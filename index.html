Frequency-Domain Patterns Across Earthquake Stations

Emiliano Hernández Castillo & Tarvin Kaur Arora

Contents

Research Question

Do different earthquakes produce similar frequency-domain patterns at the same seismic stations?

Can SOMs identify consistent spectral clusters across events?

Relevance

Understanding spectral patterns can improve hazard modelling and earthquake engineering.

Dataset Description

RAII UNAM accelerograms: 3 earthquakes, 5 stations each, 3 components per station.

Methodology

  • Windowing & Standardization
  • FFT
  • SOM Clustering
  • Visualization & Cross-Event Comparison

Data Pre-Processing

256-sample windows, non-overlapping; FFT & power spectra; standardization.

Machine Learning

SOM used to cluster spectral windows; PCA used for dimensionality reduction.

U-Matrices

Visualizing SOM node distances to reveal cluster boundaries.

Station Hit Maps

Shows which spectral regimes each station activates.

Results

SOM node spectra exhibit consistent shapes across events.

Station U-Matrices

Stations have unique spectral fingerprints linked to geology and location.

Cluster Stability

Stations 0–2 stable; stations 3–4 more event-dependent.

Similarity Comparisons

Cosine similarity >0.9 for most clusters → consistent patterns.

PCA Projections

Clusters remain coherent across events with minor shifts.

Interpretation

Stable station behaviour; similar spectral structures; proportion differences per event.

Conclusions

Earthquakes share stable spectral regimes; differences lie in cluster occupancy.

Limitations

  • Only 3 earthquakes
  • Small dataset
  • SOM hyperparameter sensitivity
